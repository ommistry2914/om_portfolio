## 🎯 Button Styles - Complete Guide

### **Primary Button** (`.btn-primary`)
```css
Background: Solid Blue (#4F9EF8)
Text: White
Border: None
Hover: Darker blue + lift + shadow
```
**Usage**: "Let's Talk", "Start a Conversation"

### **Gradient Button** (`.btn-gradient`)
```css
Background: Blue → Purple Gradient
Text: White
Border: None
Hover: Lift + enhanced shadow
```
**Usage**: "View Projects", "Send Message", Scroll-to-top

### **Accent Button** (`.btn-accent`)
```css
Background: Cyan (#0EA5E9)
Text: White
Border: None
Hover: Darker cyan + lift + shadow
```
**Usage**: "Download Resume"

### **Secondary Button** (`.btn-secondary`)
```css
Background: Transparent
Border: Gray
Text: Foreground
Hover: Muted bg + primary border + primary text
```
**Usage**: "Get In Touch"
